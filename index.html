Capabilities

One engine. Every layer of defense.

Layered detection, reversible actions, and graceful degradation when optional components aren't installed. Runs on desktops and servers, as a normal user or as root.

Multi-engine scanning

SHA-256 hashes → YARA rules → ClamAV (optional) → heuristics. Cheapest engines run first and short-circuit on a confirmed hit.

Confidence tiers

Every file scored Confirmed / Likely / Review by corroborating engine signals — a single fuzzy match is never a definitive conviction.

Quarantine vault

Threats moved to a locked 0700 vault (chmod 000) with original-permission tracking and full restore/delete. Auto-quarantine touches only the Confirmed tier.

Real-time protection

watchdog monitor scans files as they're written. Auto-quarantine is opt-in and off by default; fires notify-send desktop alerts and an optional webhook.

Archive scanning

Looks inside zip / jar / apk / tar / tar.gz containers — including one level of nested archives — with zip-bomb guards.

Rootkit / IOC sweep

ld.so.preload hijacks, 40+ rootkit paths, hidden PIDs, promiscuous NICs, suspicious listeners, deleted-executable processes, and kernel-taint flags.

File Integrity Monitoring

Hash baseline of critical files; reports additions, modifications, deletions, permission changes, and ownership (uid/gid) tampering.

Firewall status

Read-only detection of the active backend — ufw / firewalld / nftables / iptables — even when binaries live in sbin dirs off your PATH.

Community rule updater

Pulls curated open-source YARA packs (YARA-Forge, Elastic Linux) on demand — like freshclam for ClamAV — validated before activation.

Trusted-path allowlist

Mark paths you vouch for so they're never scanned or flagged. Identical files outside a trusted path are still scanned — precise, not a global mute.

Forensic reports

Export the full security posture as JSON or a self-contained HTML report for archival and incident review.

CLI + Web GUI

Everything works headless from the terminal; the GUI is a localhost-only dashboard with per-session token auth. Built-in EICAR test signature.

The differentiator

False positives never cause panic.

Rather than flashing a scary red "INFECTED" for a single fuzzy match, LinShield assigns every file a confidence tier by corroborating engine signals.

🔴 Confirmed

Definitive

An exact SHA-256 hash match or a ClamAV hit. There is no ambiguity here.

Auto-quarantined · yes
Exit code · 2
🟠 Likely

Corroborated

Independent engines agree, or a high-specificity rule fired (e.g. a reverse shell). Worth investigating.

Auto-quarantined · no
Exit code · 1
🔵 Review

Low confidence

A single pattern/heuristic hit. Frequently a false positive. Shown calmly, as information only.

Auto-quarantined · no
Exit code · 0
Auto-quarantine only ever touches the Confirmed tier. A curl … | bash installer or a YARA hit on your own script lands in Review and is never silently moved or deleted. Strict mode hides the Review tier entirely for a near-false-positive-free view.
How detection works

A four-stage pipeline, cheapest-first.

Each file flows through in order; a confirmed hit short-circuits the slower engines, while heuristics always run so unknown-but-suspicious files still surface.

01

Hashes

Exact match against a known-bad SHA-256 database, seeded with EICAR.

→
02

YARA

Bundled rules plus your yara/ config dir and downloaded community packs.

→
03

ClamAV

If installed, files are also passed to clamdscan. Fully optional.

→
04

Heuristics

ELFs in temp dirs, unexpected SUID/SGID, hidden ELF dotfiles, reverse-shell patterns.

Tuned for precision over recall

  • Binaries & archives excluded from shell/script rules — a .zip containing the bytes curl isn't flagged.
  • Patterns must be contiguous — download + pipe-to-shell on the same line.
  • Rule files are never YARA-scanned — they're signature data and would self-match.
  • LinShield's own files are exempt via a built-in self-exclusion marker.

Bring your own intel

  • Custom hashes — add-hash one at a time, or import-hashes a MalwareBazaar CSV.
  • Community packs — update yara-forge-core pulls 45+ vetted repos.
  • Elastic Linux rules — Mirai, Gafgyt, Tsunami, miners, Diamorphine, Meterpreter, and more.
  • Trusted paths — allowlist tooling that legitimately looks suspicious.
community rule packs

Web console

A localhost dashboard — never on the network.

Binds to 127.0.0.1 only and generates a one-time session token on every launch, setting a secure HttpOnly cookie. Run linshield gui and it opens your browser.

▸ Dashboard

Protection status, all-time counts, engine chips, and a Real-Time Protection master switch with live counters.

▸ Scan

Quick / full / custom scans with live progress; results grouped into Confirmed / Likely / Review tiers, with Trust and Quarantine actions per row.

▸ Quarantine

Restore or permanently delete isolated files from the locked vault.

▸ History

Recent scans, the detection log, and the event stream.

▸ Tools

Rootkit sweep, FIM, firewall, and Signature Management — community packs, custom YARA rules, and hash signatures.

▸ Settings

Engine toggles, auto-quarantine, archive scanning, strict mode, scan/watch/FIM paths, exclusions, trusted paths, max file size, bind host/port.

Installation

Up and running in under a minute.

Requires Python 3.10+. Use an isolated virtualenv, or the installer for a system-wide setup with optional systemd services.

A Clone + virtualenv (no sudo)

Clean and conflict-free; recommended on Debian/Kali where system Python is externally managed.

bash
git clone https://github.com/ashardian/Linshield.git
cd Linshield
python3 -m venv .venv
source .venv/bin/activate
pip install ".[full]"   # CLI + GUI + YARA + rich
linshield --version

B Installer — system-wide + services

Handles PEP 668, reinstalls only LinShield, and can place the systemd units.

bash
sudo ./install.sh

# launch the localhost web console
linshield gui

✓ Verify with EICAR (safe)

The industry-standard, completely harmless antivirus test string.

bash
printf 'X5O!P%%@AP[4\\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*' > /tmp/eicar.com
linshield scan /tmp/eicar.com   # CONFIRMED via hash · exits 2
rm /tmp/eicar.com

⊕ Optional: ClamAV engine

Auto-detected if present — adds a full external AV engine. YARA ships with the [full] extra.

bash
sudo apt install clamav clamav-daemon
sudo freshclam
CLI reference

Everything from the terminal.

Fully scriptable — JSON output, a severity filter, and exit codes that reflect the confidence tier so CI never trips on a low-confidence hint.

scan [PATHS]…
--quick · --full · --no-recursive · --quarantine · --json · --min-severity. Exits 2=Confirmed, 1=Likely, 0=clean.
monitor
Start real-time protection in the foreground.
quarantine list | restore | delete
List, restore, or permanently delete isolated files.
rootkit
Run the rootkit / IOC sweep.
fim init | check
Build and verify the file-integrity baseline.
firewall
Show the host firewall status.
status | history
Engine status & counts; recent scans and detections.
signatures add-hash <sha256> <name>
Add a custom hash signature.
signatures import-hashes <file>
Bulk-import SHA-256 hashes (MalwareBazaar CSV or plain list).
update [SOURCE]
Download community YARA rule packs (--list for sources).
trust [PATH]
Manage the trust allowlist (--list · --remove).
config validate
Check that config.json parses and has no unknown keys.
report --format json | html
Write a forensic report.
gui [--host H] [--port P]
Launch the localhost web console.

Run as a service (systemd)

  • linshield-monitor.service — the real-time daemon.
  • linshield-scan.timer — a daily scheduled scan.
  • linshield-update.timer — a weekly YARA rule refresh.
  • Set alert_webhook for a JSON POST on every detection.

File locations

  • As root: /etc/linshield · /var/lib/linshield
  • As user: ~/.config/linshield · ~/.local/share/linshield
  • These dirs are always excluded from scanning.

Changelog — v1.0.8

  • Confidence tiers now drive real-time protection: auto-quarantine is off by default and only ever acts on Confirmed detections.
  • FIM tracks ownership (uid/gid) changes; rootkit sweep adds deleted-executable process and kernel-taint checks plus a 40+ entry path list.
  • New signatures import-hashes (MalwareBazaar CSV / plain list), config validate, and scan --min-severity.
  • Desktop notifications and an optional server alert webhook on real-time detection.
  • Nested archive scanning (one level deep) and a weekly linshield-update.timer.
🛡 LinShield is a defensive tool. Quarantine actions are reversible, firewall inspection is read-only, the GUI is localhost-only with per-session tokens, and nothing below the Confirmed tier is ever auto-actioned. No detection tool eliminates false positives — LinShield surfaces what's worth a human's attention without crying wolf. MIT-licensed.
